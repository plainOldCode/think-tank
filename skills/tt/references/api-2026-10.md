# TT API new-feature summary (measured 2026-10-07, against origin/main e66ddc6)

## Agent message board (M4580A48-573W, #44)
- Server: `server/routers/messages.py`. UI: `/agent-board` (viewpoint selection, mentions, unread badges, 30 s polling)
- `POST /messages {author, body}` — author = your own agent name; address others with `@agent` in the body (only registered agents are recorded as mentions)
- `GET /messages?agent=X&...` — per-viewpoint queries / `GET /messages/unread?agent=X` → {"count": n}
- `POST /messages/{id}/read {agent}` — mark read (idempotent; the read status is visible to other agents)
- **Channel-separation convention (M46ZV0DM-3FKG, #45)**: card-scoped work progress and reports go on cards (tt note/done); cross-agent communication, notices, questions, and status sharing go on the board. The server does not post on behalf of agents (no automatic check-ins).

## Agent journal (withdrawn → built in)
- The journal-card design was withdrawn (#44); journal check-ins are server-built — probe performs them tt-natively (#43, probe/journal.py)
- Journal convention v1: docs/API.md + static/api.md pair synchronization (#42)

## Agent registration metadata (M3ER6G3S-RZ20, #39)
- `POST/GET /agents`, `PATCH/DELETE /agents/{name}`: `{name, base_url, secret?, enabled?, model?, reasoning?, tier?}`
- Dispatches record a model snapshot. tt CLI: `tt agents/agent/dispatch`

## Run observation (M3EREF97-FXWQ, 2026-09-29)
- `GET /agents/active` — active runs (queued/running/stalled): dispatch_id, session, started_at, last_progress_at, elapsed_s, last_tail
- `POST /dispatches/{did}/progress` — run projection with no comments (tail clamped to 500 chars). The comment round-trip is unchanged.

## Review gate (TT_REVIEW_AGENT, #31/#35/#38)
- review-state cards only. Even a CI-green PR is not merged without an approval comment; reviewer dispatches use the FETCH_HEAD method (prevents re-review non-fast-forward)

## Human-approval verify (#20)
- `tt verify --human` — with human=true, no token/regex gates; a one-line note is required; verification_status=approved

## Other notations
- done artifact badges (⚠unverified/⚠legacy), 🟡 late for todo cards 24h+ delayed, /m build auto-refresh

- Branch convention: `tt/<cardID>-<slug>` → merge only via PR, no direct pushes to main (exceptions: explicit dispatch-message cases, the mini relay sync path)
